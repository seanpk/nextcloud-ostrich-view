# Backing Technology

* Files will be stored on Nextcloud.
* Tasks are kept using the Tasks Android app and are synced to Tasks on Nextcloud.
* A paper calendar is used.

The Nextcloud server is self-hosted and accessible at cloud.example.com through a Cloudflare tunnel.

So we have access too:
1. The Beelink ME Mini (Intel N150, 16GB RAM) that hosts Nextcloud
2. Admin access to Nextcloud to install Apps and/or configure settings
3. Admin access to the Beelink itself, say to run a separate docker container
4. A Cloudflare free tier
