# Project Goal

Create a file viewing web app with extremely easy use and little to no complications. The app should be able to display in a simple way how folders are organized, with easy large buttons to use, and it should be able to display .png .pdf .jpg nextcloud tasks and so on in a friendly way that does not require any of the files to be downloaded to fully view them. The owner should be able to set which files/folders/tasks  that can be seen on the web app

# User Experience

Upon loading the site, the user puts in their own password to grant access to view the files on their own session. Once they have logged in that session, they are greeted with buttons to go to each folder/task group that is available to view. Clicking once on a button should bring the user into a list of what's in the files, and if there are any other sub files, it should display them on top in the same format they were displayed in the home menu. There should be a dedicated back button that is always accessible and clear no matter what page the user is looking at. The file menus should be previews of the document/photo with the name listed below in clear text. When the user clicks once on the file, it should open it in a file viewer. The back button should still be accessible for them to use and get out of seeing the file. On the home page, there should be a new since you last looked session, that way the user can see what has updated or been added to the folders. If a new document has been added, the document name should be shown along side its preview, but the folder that is in should also be displayed in a non-obtrusive manor. Throughout the website, that manor should be used whenever the user is viewing files in a folder. The user should be able to switch from seeing the files, to being able to see tasks. Each task section should be organized in the same fashion as the folders. Once the user clicks on a task category, they should see the uncompleted tasks and all of their details in full. Complete task should be shown with the most recently completed at the top.
